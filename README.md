# Skybound Sprout

An original, self-contained 2D platform adventure for desktop and mobile browsers. All character art, scenery, effects, and synthesized sounds are generated by the game; it has no image or audio asset downloads and no build step.

## Play locally

1. Open `index.html` in a current version of Chrome, Edge, Firefox, or Safari.
2. Select **Play adventure**. Sound starts after the first click, as required by browser audio policies.

For more reliable local storage, especially in Safari, serve this folder from a local static server and open its local address. Any static server works; for example, from this folder run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Controls

- **A / D** or **Left / Right**: move
- **Space**, **W**, or **Up**: jump; press again in the air for a double jump
- **Shift**: run
- **X** or **J**: throw a seed after collecting a fire flower
- **Esc** or **P**: pause
- Touch screens: use the on-screen movement, jump, and seed buttons

## Adventure

Explore eight original stages: Sunpetal Meadow, Mushroom Canopy, Glimmerdeep Grotto, Cinderpeak Keep, Brambleback Citadel, Cloudbreak Causeway, Sunken Pearl Reef, and Amberwind Dunes. Each route now continues into a longer challenge gauntlet with extra gaps, moving platforms, enemies, coins, rewards, and a late checkpoint. Brambleback Citadel's longer approach leads into its boss fight. Unlocked levels, best scores, total coins, and sound preference are saved in browser storage.

## Publish

This is a static website. Upload the contents of this folder to any static web host, such as GitHub Pages, Netlify, Cloudflare Pages, or an object-storage website endpoint. Set the publish directory to this folder and use no build command. Keep `index.html`, `style.css`, and `game.js` together at the site root.

## Files

- `index.html` — game canvas, menu, HUD, and touch controls
- `style.css` — responsive layout and visual interface
- `game.js` — game loop, player physics, collisions, level data, enemies, boss, progression, effects, and synthesized audio
